## 戦略: breakout

```

  フィルター
    range_compression  (レンジ高値 - 安値) / H4 ATR <= max_range_atr（保ち合い）

    signal_id はレンジ高値を作った H4 足の時刻。同じ高値のブレイクには 1 回しか入らない
    （だましで戻った後の再ブレイクでは再エントリーしない）。

```
